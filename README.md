# geoguessr

Jeu de géographie façon GeoGuessr, à lancer sur son PC Windows.

## Jouer

1. Va dans **[Releases](../../releases/latest)** et télécharge `WorldGuessr-windows.zip`.
2. Dézippe-le (clic droit, « Extraire tout »).
3. Double-clique sur **Jouer a WorldGuessr.exe** : le jeu s'ouvre en plein écran.

Pour quitter : **Alt+F4**.

Si Windows affiche « Windows a protégé votre ordinateur », clique sur « Informations complémentaires » puis « Exécuter quand même » : le lanceur n'est pas signé.

Il faut Windows 10 ou 11, Microsoft Edge ou Google Chrome, et Internet pour les images Street View. Rien d'autre à installer.
