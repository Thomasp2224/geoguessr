# geoguessr

Jeu de géographie façon GeoGuessr, à lancer sur son PC Windows ou son Mac.

## Jouer sur Mac

1. Va dans **[Releases](../../releases/latest)** et télécharge `WorldGuessr-mac.zip`, puis double-clique dessus pour le dézipper.
2. **La première fois** : clic droit (ou Ctrl+clic) sur **Jouer a WorldGuessr.command**, puis « Ouvrir », puis encore « Ouvrir ». Si macOS refuse sans proposer « Ouvrir » : Réglages Système > Confidentialité et sécurité, tout en bas, « Ouvrir quand même ».
3. Les fois suivantes, un double-clic suffit. Le jeu s'ouvre en plein écran dans Google Chrome (ou dans Safari si Chrome n'est pas installé).

Pour quitter : **Cmd+Q**. Avec Safari, ferme la fenêtre Terminal. Il faut macOS 13.5 ou plus (Mac M1 à M4 ou Intel).

## Jouer sur Windows

1. Va dans **[Releases](../../releases/latest)** et télécharge `WorldGuessr-windows.zip`.
2. Dézippe-le (clic droit, « Extraire tout »).
3. Double-clique sur **Jouer a WorldGuessr.exe** : le jeu s'ouvre en plein écran.

Pour quitter : **Alt+F4**.

Si Windows affiche « Windows a protégé votre ordinateur », clique sur « Informations complémentaires » puis « Exécuter quand même » : le lanceur n'est pas signé.

Il faut Windows 10 ou 11 et Microsoft Edge ou Google Chrome.

Dans les deux cas, il faut Internet pour les images Street View, et rien d'autre à installer.
